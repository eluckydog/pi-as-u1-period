## Chern Number — Quantum Hall Effect

```
C = (1/2π) · ∫_BZ F(k) · d²k

F(k) = Berry curvature, integrated over the Brillouin zone (BZ).
C must be an integer — not a coincidence, a topological necessity.
```

**Why π forces integer quantization:**
- The Brillouin zone is a torus T² = S¹ × S¹
- Berry curvature F is the curvature 2-form on a U(1) principal bundle
- The Chern class = (1/2πi) · ∫ curvature = integer

**Physical consequence:** `σ = C · e²/h` — the quantum Hall conductance.

Measured to **±10⁻⁹ precision**. π directly participates in defining a topological invariant that protects the integer value of C against any continuous deformation.

## DNA Supercoiling — Lk = Tw + Wr

```
Lk = Tw + Wr   (linking number = twist + writhe)

Lk = base_pairs / helical_turn   in units of 2π
For B-DNA: Lk = bp / 10.5   (one complete helical turn per 10.5 bp)

Lk is a topological invariant — cannot change without breaking the DNA backbone.
```

**Topoisomerase operations:**
- Type I: Lk → Lk ± 1 (one 2π twist)
- Type II: Lk → Lk ± 2

**π's diagnostic role:** Abnormal Lk → supercoiling tension → replication/transcription stalls. This is exploited in **anticancer drugs** — etoposide targets Topoisomerase II, causing lethal DNA breaks in rapidly dividing cells.
